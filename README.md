# Tarea 1 — Operaciones Matemáticas

## Descripción
Este proyecto consiste en una aplicación de escritorio que permite realizar operaciones matemáticas básicas entre dos números introducidos por el usuario.

La interfaz del programa cuenta con dos cuadros de texto (**TextBox**) donde el usuario ingresa los valores numéricos. Al presionar el botón **Calcular**, el sistema realiza automáticamente las operaciones matemáticas correspondientes.

Los resultados se muestran en diferentes **Label**, permitiendo visualizar de manera clara el resultado de cada operación realizada.

---

## Funcionalidades
- Ingreso de dos números.
- Cálculo de operaciones matemáticas básicas.
- Visualización de resultados en la interfaz.
- Interfaz simple y fácil de usar.

Las operaciones disponibles son:
- **Suma**
- **Resta**
- **Multiplicación**
- **División**

---

## Tecnologías Utilizadas
- **Lenguaje:** C#
- **Framework:** .NET (Windows Forms)
- **Entorno de desarrollo:** Visual Studio 2022

---

## Uso o Ejecución
Para ejecutar el proyecto se deben seguir los siguientes pasos:

1. Clonar el repositorio desde GitHub.
2. Abrir el archivo `.sln` en **Visual Studio 2022**.
3. Compilar el proyecto.
4. Ejecutar la aplicación presionando **F5** o el botón **Iniciar**.
5. Introducir los dos números en los campos correspondientes y presionar **Calcular** para ver los resultados.
